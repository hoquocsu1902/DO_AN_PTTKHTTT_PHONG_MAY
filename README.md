# ĐỒ ÁN PHÂN TÍCH VÀ THIẾT KẾ HỆ THỐNG THÔNG TIN

## Tên đề tài
Phân tích và thiết kế hệ thống thông tin quản lý sự cố,
bảo trì và tài sản thiết bị tại phòng máy trường đại học.

## Thông tin nhóm
- Trường: Đại học Công Thương TP.HCM
- Học phần: Phân tích và Thiết kế Hệ thống Thông tin
- Nhóm: 10
- Thành viên: 
    + Hồ Quốc Sử
    + Cao Minh Luân
    + Nguyễn Quốc Thành

## Cấu trúc
- 00_QuanLyNhom: Kế hoạch, phân công và tiến độ
- 01_KhaoSat: Khảo sát và tài liệu nghiệp vụ
- 02_BaoCaoWord: Báo cáo đồ án
- 03_UML: Các sơ đồ phân tích và thiết kế
- 04_CSDL: Mô hình quan hệ và SQL Server
- 05_GiaoDien: Thiết kế giao diện
- 06_BanNopCuoi: Tài liệu nộp cuối cùng

## Quy định làm việc
1. Pull trước khi bắt đầu chỉnh sửa.
2. Chỉ sửa các tài liệu được phân công.
3. Commit với thông điệp mô tả rõ thay đổi.
4. Không xóa tài liệu của thành viên khác.
5. Kiểm tra file trước khi đưa vào bản nộp cuối.
